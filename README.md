# Inter-VLAN Routing and Network Connectivity Using Cisco Packet Tracer

## Project Overview

This project demonstrates Inter-VLAN Routing and communication between multiple VLANs using Cisco Packet Tracer.

The network consists of two routers, two switches, and multiple end devices organized into different VLANs.

The main objective is to establish communication between devices belonging to different VLANs and different IP networks through router-based routing.

## Project Objectives

- Create multiple VLANs for different departments.
- Configure IP addressing for each VLAN.
- Enable communication between different VLANs.
- Configure routing between two network segments.
- Understand how routers facilitate communication between separate networks.
